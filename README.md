# Telegram Bot для розыгрышей

Тестовове задание: бот для проведения розыгрышей и промоакций.

## Возможности
- Получение промокодов от партнеров
- Ежедневные розыгрыши призов
- Накопление шансов на главный приз
- Статистика и выгрузка данных для администраторов

### Для всех пользователей
- /start - запустить бота

### Для администраторов
- /export - выгрузка статистики
- /statistics - подсчет статистики
- /final - провести финальный розыгрыш

## Стек
Go 1.22+, PostgreSQL 16, GORM, Docker

## Выбор Telegram
1. Простота создания бота
2. Простота тестирования взаимодействия бота с пользователем

## Структура проекта

- `main.go` - точка входа, инициализация бота
- `handlers.go` - обработчики команд Telegram
- `daily_draw.go` - логика ежедневных розыгрышей
- `final_draw.go` - логика финального розыгрыша
- `prize_checker.go` - фоновый воркер проверки призов
- `models.go` - структуры данных (User, Partner, Draw и т.д.)
- `database.go` - подключение к PostgreSQL
- `export.go` - формирование выгрузки
- `keyboads.go` - кнопки
- `state.go` - глобальные переменные
- `statistics.go` - статистика и аналитика
- `utils.go` - вспомогательные функции

## Запуск
```bash
# 1. Склонировать репозиторий
git clone https://github.com/your-username/tg_bot_go.git
cd tg_bot_go

# 2. Создать .env из шаблона и заполнить API_TOKEN, ADMIN_ID, пароли БД
cp .env.example .env

# 3. Запустить
docker-compose up -d --build
